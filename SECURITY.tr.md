# Güvenlik bildirimi

[English](SECURITY.md)

Güvenlik açığı için etkinse GitHub özel güvenlik bildirimi veya depo sahibinin GitHub profili üzerinden özel iletişim kullanın. Public issue içine saldırı şifreleri, gerçek SAP sistemleri, sırlar veya müşteri dosyaları koymayın. Kurgusal en küçük tekrar örneğini paylaşın. Önizlemeler temiz Windows/canlı SAP kabulünü tamamlamamıştır. Yalnız güncel önizleme düzeltmeleri sürdürülür; üretim desteği taahhüdü verilmez.
